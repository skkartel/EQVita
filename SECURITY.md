# Security Policy

EQVita is a PS Vita homebrew project. Please be careful with random reuploads.

## Official Builds

Official builds only come from:

- https://github.com/shev0k/EQVita
- https://github.com/shev0k/EQVita/releases

If a VPK or plugin came from somewhere else, treat it as unofficial.

For normal people: do not install random reuploads.

For people who know the pain: compare release checksums before testing or sharing binaries.

## Reporting Security Issues

If you find a suspicious build, malicious reupload, or security issue, please report it through GitHub or contact the maintainer privately if possible.

Please include:

- where the file came from;
- file names;
- SHA256 checksums;
- what looked suspicious;
- screenshots or links if useful.

## Checksums

Release builds should include checksums for:

- `EQVita.vpk`
- `eq_speaker.skprx`

Use the checksum file to confirm that the files you installed match the official release.

## Support Scope

Support is only for official EQVita builds.

Modified forks, repacks, or random uploads may behave differently and are not trusted.
