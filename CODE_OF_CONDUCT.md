# Code of Conduct

EQVita is a small hobby project, but people should still be normal to each other.

## The Short Version

- Be respectful.
- Stay on topic.
- Do not harass people.
- Do not spam issues or pull requests.
- Do not upload or link suspicious binaries.
- Do not use EQVita's name to push malware or fake builds.

## Good Contributions

Helpful reports include:

- Vita model and firmware;
- EQVita version;
- output used, like speakers, wired headphones, or Bluetooth;
- preset used;
- clear steps to reproduce;
- `ur0:data/eqvita/app.log` when useful.

It is fine to be frustrated when something breaks. Just keep the report useful.

## Not Okay

The maintainer may delete, close, hide, or block behavior like:

- personal attacks;
- harassment;
- slurs or hateful comments;
- malware links;
- fake EQVita builds;
- repeated low-effort noise after being asked to stop.

## Reporting Problems

If something needs maintainer attention, open a GitHub issue or contact the maintainer privately if the issue is sensitive.

Security-related problems should follow [SECURITY.md](SECURITY.md).

## Scope

This applies to EQVita's GitHub repo, issues, pull requests, releases, and any official project spaces.
